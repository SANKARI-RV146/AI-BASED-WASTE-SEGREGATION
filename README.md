AI-Based Waste Segregation Web Application

This project is developed as part of an AI for Sustainability initiative.
It demonstrates how AI-inspired decision logic can support responsible
waste segregation and environmental sustainability.

SDG Alignment:
- SDG 12: Responsible Consumption and Production

Problem Statement:
Improper waste segregation leads to inefficient recycling, environmental
pollution, and health risks.

Solution:
A Streamlit-based web application that allows users to upload waste images
and receive intelligent waste classification along with proper disposal
guidance.

AI Role:
The application uses AI-inspired rule-based classification logic to
simulate intelligent decision-making, which can be scaled to advanced
computer vision models.

Target Users:
- Households
- Students
- Municipal workers

Responsible AI Considerations:
- No personal data collection
- Transparent and explainable logic
- Awareness-focused and ethical design

Technology Stack:
- Python
- Streamlit
- Pillow

Deployment:
The application is deployed using Streamlit Community Cloud.
